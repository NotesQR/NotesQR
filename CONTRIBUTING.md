# Contributing to NotesQR

Thanks for helping. NotesQR is donation-funded — time and money both count.

## Donate

If NotesQR already works for you: **[notesqr.com/donate](https://notesqr.com/donate)** (PayPal or BTC).

## What lives where

| Repo | What to send |
| --- | --- |
| **[NotesQR/NotesQR](https://github.com/NotesQR/NotesQR)** (this repo) | README, docs assets, product-page issues |
| **[NotesQR/notesqr-share](https://github.com/NotesQR/notesqr-share)** | CLI, MCP, agent plugins — **this is where code PRs go** |

## Issues

Open an issue here for product bugs, docs gaps, or feature ideas. Include OS, browser or CLI version, and whether both peers stayed online.

## Pull requests

- **CLI / MCP:** fork [notesqr-share](https://github.com/NotesQR/notesqr-share), keep PRs small, match existing style.
- **This repo:** README and `media/` only. Prefer facts over slogans (P2P, no hosted copy, sender must stay online).

## Code of conduct

Be specific, be kind, no drive-by spam. Security reports: use the contact form on [notesqr.com/contact](https://notesqr.com/contact) rather than a public issue if the bug could leak files.
